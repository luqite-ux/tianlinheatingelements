# 首页媒体点位计划

| sectionId | 采购任务 | 媒体与来源 | 桌面 / 390px | CTA |
|---|---|---|---|---|
| hero | 快速理解产品与定制能力 | `banner/1.jpg`、`2.jpg`、`3.jpg` 全部进入轮播 | 桌面 16:7 完整合成；手机独立安全区，不裁掉产品/设备主体；无 JS 显示首张 | View Products / Send RFQ |

| manufacturing | 真实制造与车间 | `公司图片优化` 中厂区、车间、绕线、装配图 | 视觉拼贴 / 自然比例纵向 | View Manufacturing |

| clients | 展示资料提供的合作客户 | PPT 第 8 页独立 Logo；采用 `react-bits:logo-loop` | 左向循环、悬停/按钮暂停；手机与减弱动画静态换行 | Start a Project |
| process | 解释询盘到批量合作 | Requirement → Drawing Review → Sampling → Testing → Production | 图形化流程 / 纵向步骤 | Request a Sample |
| faq | 回答定制、MOQ、打样、交期、质检 | 无媒体；分组折叠 | 双栏 / 单栏 | Contact Engineering |
